# plant-data

One skill for software that touches plant or industrial data.

- `connecting-to-plant-data`: how to read live data from OPC UA, MQTT/Sparkplug B, REST, MES, SQL, historians or PLC tag servers, and send setpoints or commands back, without hard-coded hosts or credentials and with safe write rules. Example: "My digital twin must read tags from our OPC UA server and suggest setpoints. How do I connect it safely?"

## Requirements

None. It is guidance for Claude; it installs nothing and connects to nothing by itself.

## Install

```text
/plugin install plant-data --marketplace TheMattHub/claude-skills
```
