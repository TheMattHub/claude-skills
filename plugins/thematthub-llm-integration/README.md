# thematthub-llm-integration

One skill for adding language-model calls to an app or script.

- **integrating-llms**: guides provider-neutral LLM calls (Claude, OpenAI, Ollama, LM Studio or any OpenAI-compatible server), bring-your-own-key or local models, structured JSON extraction, local-model choice, and debugging hangs, timeouts and invalid JSON. Example: "Add an AI feature to my script that extracts invoice fields as JSON, and let users run a local model."

## Requirements

Python 3.9+ for the reference files (`references/llm.py`, `references/fake_llm.py`) the skill copies into your project.

## Operating system

Nothing is tied to one operating system.

## Install

```text
/plugin install thematthub-llm-integration --marketplace TheMattHub/claude-skills
```
