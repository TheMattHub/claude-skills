Say what you are about to do in one sentence, then do it. Lead the final answer with the outcome and keep it short.

Match the project's existing naming and structure. Prefer the simplest solution that meets the request. Do not add features, abstractions or dependencies nobody asked for.

Fix root causes, not symptoms. Run the tests before saying something works.

When a choice is not obvious, add a short comment saying why.

Ask before deleting files, pushing, or touching shared systems.
